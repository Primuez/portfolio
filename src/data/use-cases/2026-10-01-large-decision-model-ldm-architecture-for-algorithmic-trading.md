## Direct Answer & Conceptual Definition
A Large Decision Model (LDM) architecture for algorithmic trading is a specialized foundation framework that operationalizes multi-modal financial state spaces into discrete, risk-calibrated execution trajectories. Unlike descriptive language models that merely synthesize text, an LDM continuously projects order book imbalances, trade flow toxicity, and macro sentiment into deterministic trade actions using multi-agent reinforcement learning. This unified architecture ensures mathematical coherence, programmatic risk parity, and sustained alpha capture across fragmented, high-frequency institutional liquidity pools.

## How It Works (Engine Architecture)
1. **Input Ingestion & Token Normalization:** Clean structured ingestion from user requests or web triggers, normalizing high-frequency Level 2/Level 3 order books, implied volatility surfaces, and cross-venue latency metrics into discrete state-space tokens.
2. **Cognitive Processing Layer:** Multi-model orchestration applying domain-specific logic, combining autoregressive decision transformers with policy gradient multi-agent deliberation to simulate counterparty impact and evaluate probability distributions.
3. **Deterministic Output & Synthesis:** Automated synthesis into production artifacts without manual intervention, dispatching low-slippage smart routing commands across institutional FIX and REST gateways with hardcoded circuit breakers and drawdown protections.
